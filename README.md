# 🚀 منصة سايسوفت للحلول الرقمية (Saysoft Digital Solutions Platform)

> **منصة سحابية متطورة لإدارة وعرض وترخيص أكثر من 30 منظومة برمجية مؤسسية SaaS، مصممة كبديل سيادي فائق السرعة والأمان لمنصات WordPress التقليدية.**

---

## 📌 نبذة عامة عن المشروع
منصة **سايسوفت للحلول الرقمية** (`saysoft_web`) هي نظام متكامل لإدارة المنتجات البرمجية السحابية وحلول إدارة الأعمال للمؤسسات، العيادات، المدارس، شركات الحراسة، محطات الخرسانة، والمجمعات السكنية. 
تم بناء المنصة باستخدام **Node.js (Express)** و **SQLite** عبر **Prisma ORM**، مع محرك قوالب **EJS** وواجهة مستخدم حديثة تدعم **ثنائية اللغة (العربية والإنجليزية)** بشكل كامل، و **5 ثيمات لونية حية**، و **3 أوضاع عرض متجاوبة (كمبيوتر، تابليت، محمول)**.

---

## 🛠️ البنية التقنية (Tech Stack)
- **بيئة التشغيل:** Node.js v20+ LTS / v22 LTS
- **إطار العمل الخلفي:** Express.js 4.x
- **محرك القوالب:** EJS (Embedded JavaScript)
- **قاعدة البيانات:** SQLite (عبر `@prisma/client` و Prisma CLI)
- **إدارة الجلسات والأمان:** `express-session`, `bcrypt`, `csurf`
- **رفع ومعالجة الوسائط:** Multer مع فرز تلقائي في مجلدات مخصصة (`/uploads/logos`, `/uploads/screenshots`)
- **الأيقونات والخطوط:** FontAwesome 6 Free وخط Cairo العربي الحديث
- **إدارة العمليات الإنتاجية:** PM2 Process Manager
- **خادم الويب العكسي والإنتاج:** Nginx + Let's Encrypt SSL Certbot

## 🌟 أبرز المميزات والخصائص

### 1. واجهة الزوار والمبيعات (Client-Facing Experience)
- **كتالوج شامل للمنظومات:** استعراض أكثر من 30 منظومة مع فلترة متقدمة حسب قطاع الأعمال والبحث النصي السريع.
- **صفحة تفاصيل متكاملة لكل منتج:**
  - عرض مميزات النظام والشرح المفصل (HTML/Rich Text).
  - معرض صور تفاعلي (Screenshots Gallery).
  - فيديو يوتيوب توضيحي مدمج.
  - **رابط مباشر لتجربة التطبيق الحية (Live Demo)** للدخول الفوري وتجربة النظام.
  - جدول باقات الاشتراك (شهري، سنوي، دائم) مع إمكانية الإضافة المباشرة للسلة.
  - قسم الأسئلة الشائعة (FAQs) المخصصة لكل منظومة.
- **صفحة خدماتنا المتخصصة (`/services`):**
  - حجز وإدارة النطاقات (Domain Registration).
  - تصميم المواقع وتجربة المستخدم (UI/UX).
  - إنشاء وتطوير تطبيقات الويب السحابية (Web Apps).
  - تخصيص الأنظمة والبرمجيات القائمة.
  - تصميم وهندسة قواعد البيانات (Database Design).
  - تصميم وتطوير التطبيقات المخصصة حسب طلب الزبون.
  - الاستشارات التقنية والتحول الرقمي.
  - نموذج مراسلة واستفسار عادي متكامل في نهاية الصفحة.
- **سلة الطلبات وإتمام الشراء:**
  - إضافة باقات متعددة، حساب الإجمالي تلقائياً، والطلب السريع.
  - إرسال تفاصيل الطلب بنقرة واحدة عبر **WhatsApp API** المباشر.
  - توليد رقم طلب مرجعي فريد وحفظه في قاعدة البيانات.
- **التصميم والهوية البصرية:**
  - هيدر داكن موحد متطابق مع لون الثيم وخلفية الفوتر مع خطوط بيضاء عالية التباين.
  - تموضع الشعار الرسمي في كافة الصفحات على **أقصى يسار العنوان الرئيسي وفي نفس المستوى الأفقي**.
  - شريط أدوات موحد لقياسات أدوات التحكم العلوية بارتفاع قياسي (34px).

### 2. لوحة التحكم الإدارية (Admin Panel)
- **إدارة المنظومات والمنتجات:**
  - إضافة، تعديل، حذف، واستعراض المنظومات.
  - **حقل حالة المنتج ودورة حياة المنظومة (Product Status):**
    - `PUBLISHED`: منشور ومتاح للتعاقد والتشغيل الفوري.
    - `IN_PRODUCTION`: جاهز وفي خط الإنتاج والتشغيل الفعلي.
    - `IN_DEVELOPMENT`: قيد التطوير والبرمجة النشطة.
    - `UNDER_STUDY`: قيد الدراسة والتحليل والتخطيط.
    - `PILOT_BETA`: إطلاق تجريبي / بيتا.
    - `COMING_SOON`: قريباً / قيد التجهيز.
    - `MAINTENANCE`: قيد التحديث والصيانة.
    - `ARCHIVED`: مؤرشف / متوقف مؤقتاً.
  - **النسخ السريع بنقرة واحدة (Duplicate System):** استنساخ منظومة كاملة بجميع باقاتها وأسئلتها في ثانية واحدة لتسريع إدخال الـ 30+ منظومة.
  - **حماية العمليات الحساسة بكلمة المرور الرئيسية (Master Password):** لا يمكن حذف أي منظومة إلا بعد تأكيد كلمة مرور الطوارئ.
- **إدارة الطلبات والمبيعات:** متابعة الطلبات الواردة، تحديث حالتها، وتصفيتها.
- **إدارة الرسائل والاستفسارات:** استقبال استفسارات صفحة اتصل بنا وطلبات صفحة الخدمات.
- **إدارة الصفحات التعريفية:** تعديل صفحات "من نحن"، "اتفاقية الترخيص والاستخدام"، والسياسات.
- **مكتبة الوسائط وضبط الإعدادات العامة.**

## ⚡ التشغيل المحلي السريع (Quickstart)

```bash
# 1. تثبيت التبعيات
npm install

# 2. إنشاء وتحديث قاعدة البيانات وتوليد Prisma Client
npx prisma db push
npx prisma generate

# 3. تشغيل الخادم
node src/server.js
```

- **رابط الموقع المحلي:** `http://localhost:49141`
- **لوحة التحكم الإدارية:** `http://localhost:49141/admin/login`
- **بيانات الدخول الافتراضية:** راجع ملف [`كلمات المرور.md`](file:///c:/aassoft/saysoft_web/كلمات%20المرور.md)
